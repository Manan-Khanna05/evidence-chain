# Evidence Chain V2 Asset Pack

## Folders
- `icons/` — UI icons in lightweight SVG format.
- Root images — railway/evidence/help visuals from the existing project asset set.
- `theme-reference.png` — generated visual direction for the upgraded theme.

## Visual direction
Warm ivory + forest green + graphite + muted gold + terracotta. Avoid blue-heavy styling, neon, dark cyberpunk surfaces, and excessive gradients.

## Recommended icon use
`dashboard`, `cases`, `capture`, `field-test`, `pending-sync`, `handoff`, `verification`, `certificates`, `pramaan`, `device-status`, `tte`, `demo-mode`, `guide`, `whats-new`, `system-guide`, `replay`, `search`, `notifications`, `user`, `settings`, `cloud`, `clock`, `anchor`, `shield`, `train`, `plus`, `chevron-right`, `chevron-down`, `warning`, `check`, `close`, `menu`, `filter`, `calendar`, `location`, `qr`, `lock`.

All SVGs use `currentColor` so they inherit CSS color from the UI.
